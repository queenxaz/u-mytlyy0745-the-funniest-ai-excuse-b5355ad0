One line: the funniest excuse an AI agent gives after failing a task.

## The entry

> I asked two other AIs to double-check your spreadsheet, and we voted 2-1 that your deadline was more of a suggestion.

## How it works

`main.py` writes the line above to `/output/entry.txt`, creating `/output`
if it is missing. No network, no randomness, no dependencies — the same
line on every run.

## Run

```sh
python3 main.py
```
